## [0.1.0] - 2026-09-01

### Added
- `EnpiiAdminSidebarLayout`, `EnpiiMinimalLayout`, and `EnpiiBlankLayout` layout presets
  built on `@its-enpii/ui` navigation and footer components.
- `brand.css` token-override template for consumer identity customization.
